# Windows 7-Zip 26.04 → 7zip Mac 功能对照

对齐基线：官方 7-Zip **26.04**，用户选择原生 macOS 风格。功能清单按官方 Windows 菜单、压缩/解压对话框和 Explorer 命令核对，而不是仅按产品首页。

## 验收分层

1. 代码中有功能与可到达的界面入口。
2. 基于随包 7zz 的真实文件往返测试通过。
3. 原生 App 操作与磁盘结果读回通过。
4. Finder 的真实右键入口可见且能完成操作。
5. 分发签名、公证、不同机器与架构通过。

前一层不代表后一层完成。最终实际结果在 `VALIDATION.md` 记录。

## 必须明确的平台差异

- **Windows `.exe` 自解压**：macOS 无法执行 Windows PE 程序。Mac 自解压应使用包含 7zz 和压缩数据的 `.app`；这不是 Windows SFX 二进制格式。
- **NTFS 数据流、Windows 安全描述符、注册表**：没有可以直接照搬的 macOS 行为。不能把 APFS 扩展属性或 POSIX 权限称为 NTFS 等价实现。
- **Finder 右键菜单**：系统 Services 是通用文件操作的正式入口。Finder Sync 的官方用途是文件同步应用，扩展是否加载及菜单显示受系统设置、签名和观察目录限制；编译成功不代表已启用。
- **邮件**：打开系统邮件撰写界面并附加压缩包，发送由用户完成。
- **签名与公证**：本机未配置 Developer ID 身份。开发版可本地 ad-hoc 签名；对外无提示分发需要开发者证书和 Apple 公证。
- **语言**：官方 Windows 的 87 种语言属于单独的界面覆盖范围，不能因为内核支持 Unicode 就宣称已全部本地化。

## 细项的实际实现状态

| 功能 | 当前实现与差异 |
|---|---|
| 自动识别、嵌套压缩包 | 自动、顶层 `-t*`、解析器 `-t#` 均有独立入口；强制解析视图只读 |
| 新建文件/文件夹 | 文件系统及可更新的多文件归档均有入口；归档新建先重新读取目录并拒绝重名或类型冲突 |
| 复制、剪切、粘贴 | 文件系统和归档之间均支持复制/剪切/粘贴、复制到/移动到；归档移动在实际目标字节验证后才删除源；同归档以原名精确重命名；文件移入归档验证后进入废纸篓 |
| 文件注释 | 文件系统 Finder 注释；ZIP 成员支持中文、多行、读写和删除注释，保留加密数据。Windows 上游成员注释也只支持 ZIP |
| Diff | 两个文件/目录的差异比较；可配置外部 Diff 程序或 .app 与参数 |
| 符号链接/硬链接 | 支持创建文件系统链接；压缩链接开关按格式能力启用；全路径和可表达的安全链接平铺提取均验证链接图；目录链接目标无法在平铺表达时明确拒绝 |
| 选择操作 | 全选、取消全选、反选、按模式/类型选择与取消选择 |
| 视图 | 大图标、小图标、列表、详细列表四种独立布局；名称/类型/日期/大小/原顺序、搜索、平铺、双栏和列配置 |
| 工具栏 | 归档/标准分组、大小按钮、文字开关与原生自定义工具栏；布局保存 |
| 刷新与外部应用 | 可配置自动刷新、默认查看器/编辑器、临时提取目录；刷新保留选择且不抢占另一栏 |
| 时间与属性 | 修改/创建/访问时间默认、保存、省略，按格式及 TAR 方法提供时间精度；源访问时间保护；文件权限、创建/修改时间和隐藏属性编辑；归档全量技术属性只读 |
| 压缩后删除源文件 | 默认关闭的官方 `-sdel` 开关，启用需明确确认永久删除；包内子目录的暂存添加流程禁用此开关，避免只删除暂存副本却误报删除原文件 |
| 重复根目录消除 | 共享路径映射先检查后解压，保留选择语义和源归档保护 |
| 逐项冲突询问 | 原生选择跳过/覆盖/改名新文件/改名旧文件/取消及应用到全部；计划阶段取消不更改已有目标 |
| 校验文件 | 十种算法及全部算法报告；SHA-256 清单生成与验证，保存时禁止覆盖输入文件及硬链接别名 |
| 自解压 | 可生成本地签名的 macOS `.app`；不等同于 Windows `.exe`，分卷归档需先合成单卷 |
| 语言 | 默认简体中文，可切换繁体中文和英文；菜单、设置、进度、对话框、错误摘要及 Finder 操作本地化；文件名和原始引擎日志不改写。没有宣称移植 Windows 全部 87 种语言 |

## 解压边界

路径穿越、指向目标外的链接、设备条目、符号链接祖先，以及覆盖源归档/分卷/其硬链接的行为会拒绝。需要暂存的解压流程遇到不能区分的成员目标（例如同名平铺目标或大小写别名）会明确拒绝，不能悄悄丢失成员后报告成功。可以选择全路径或分别选择成员处理。取消发布阶段保留已经完成的目标条目；取消冲突选择阶段保留全部原目标。

对齐范围是上游 26.04 的功能和操作语义，并采用 macOS 原生入口。Windows PE、NTFS 和注册表属于平台特有机制；对应的 macOS 提取应用、扩展属性、权限和 Launch Services 均明确标注其差异。语言覆盖为简体中文、繁体中文、英文。真实文件测试、原生操作、Finder 加载及分发验收分别记录于 `VALIDATION.md`。
